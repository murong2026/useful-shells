## 1. 下载脚本
```
curl -fsSL -o install-kavita.sh https://raw.githubusercontent.com/murong2026/useful-shells/main/install-kavita.sh
```

## 2. 查看脚本内容确认无误
```
cat install-kavita.sh
```

## 3. 赋予执行权限并运行
```
chmod +x install-kavita.sh
sudo ./install-kavita.sh
```
